# MineWatch PA-08

MineWatch is an interactive single-page civic dashboard built for residents in Pennsylvania's 8th Congressional District. The application functions as a community infrastructure screening layer designed to help homeowners check, visualize, and understand abandoned mine subsidence risks across local zip codes.

## Core Technical Features
- **Dynamic Risk Evaluation Dial**: An animated structural ring tracking risk index scores (Low, Moderate, Critical) mapped to custom thresholds.
- **Geological Variable State Management**: Dynamic state handling updating local vein names (e.g., Dunmore Vein #3), mining depths, soil stability configurations, and state-backed insurance eligibility guidelines.
- **Micro-shift Environmental Simulator**: An active toggle calculating hydrological soil saturation and projecting simulated micro-shifts (+12 risk points).
- **Print Optimization Architecture**: A localized document compile engine rendering print-ready structural summaries for physical homeowner reference.

## Architecture & System Stack
- **Frontend Core**: React 18 / TypeScript
- **Design Utility**: Tailwind CSS 3
- **Development Tooling**: Vite, Bun, Prettier
